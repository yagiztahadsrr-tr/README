# Markdown Nedir?
Markdown, 2004 yılında John Gruber tarafından yaratılmış bir işaretleme/biçimlendirme dilidir. Markdown genellikle README dosyalarını biçimlerndirmek, internet forumlarında mesaj yazmak ve düz metin düzenleyici kullanarak biçimlendirilmiş metin yazmak oluşturmak için kullanılır.
# README Nedir ve Ne İşe Yarar?
README dosyası bir yazılımın amacı, kurulumu, lisans bilgisi gibi yazılım hakkında temel bilgileri içeren metin dosyasıdır. Bu bilgileri kullanıcıya sunarak yazılımın nasıl kurulacağı gibi konularda yardımcı olur.
# Proje Versiyon/Sürümleri Nedir, Nasıl Belirlenir?
Proje versiyonları, bir yazılımın veya ürünün gelişim sürecindeki farklı aşamalarını ve bu süreç sırasında yapılan değişiklikleri takip etmek için kullanılan sistemdir.
Bir projenin sürümleri sürüm numaraları ile belirlenir. Sürüm numaralandırmak için kullanılan en yaygın yöntem SemVer(Semantic Versioning) sistemidir. Bu sistemde sürüm numarası x.y.z olmak üzere üç farklı sayıdan oluşur. x büyük değişiklikler yapıldığını belirtmek için, y sistemin mevcut kullanım şeklinde herhangi bir değişikliğe sebep olmayan küçük güncellemeler için, z ise hata düzeltmeleri ve küçük iyileştirmeler için arttırılır.
